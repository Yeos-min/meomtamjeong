앱 버튼 계층 구조

현재 앱에서 사용하는 버튼을 목적과 위계 기준으로 정리했습니다. 기본 원칙은 “최종 CTA는 주황 그라데이션, 주요 행동은 갈색 Primary, 보조 행동은 베이지 Secondary, 중립 행동은 Outlined”입니다.

APPBUTTON VARIANTS

CTA

화면의 최종 행동. 한 화면에 1개만 가장 강하게 노출합니다.

취향에 맞게 찾기 내 라멘 찾기 기록 저장 길찾기

PRIMARY

중요하지만 최종 CTA는 아닌 주요 행동. 갈색 채움으로 구분합니다.

가게 상세보기 조건 적용 로그인

SECONDARY

이전, 교통수단 미선택, 일반 보조 행동. 베이지 칩 배경을 사용합니다.

이전 자전거 대중교통

SOFT / SELECTED

필터, 메뉴, 옵션처럼 누르면 상태가 바뀌는 버튼입니다.

웨이팅 없음 자가제면 도보

OUTLINED

흰 배경의 보조 행동. 홈의 지도 바로 보기, 로그인 보조 등에 사용합니다.

지도에서 바로 보기 비회원으로 시작하기 닫기

TEXT / DANGER

작은 링크성 행동과 삭제/주의 행동. 삭제는 실제 반영 전 확인이 필요합니다.

전체 보기 지도에서 보기 삭제

WHERE TO USE
화면 버튼 계층 상태 규칙
홈 취향에 맞게 찾기 / 지도에서 바로 보기 / 전체 보기 CTA Outlined Text 가장 중요한 진입은 CTA, 지도 바로 이동은 Outlined, 목록 더보기는 Text로 약하게 둡니다.
취향 찾기 X / 이전 / 다음 / 내 라멘 찾기 / 선택 카드 Icon Secondary CTA Selection 현재 질문 미선택 시 다음 비활성. 마지막 단계는 전체 답변 완료 시 내 라멘 찾기 활성.
지도 검색바, 필터 칩, 조건 적용, 가게 상세보기 Soft Selected Primary 선택된 필터는 갈색 선택 상태로 유지합니다. 조건 적용/상세보기는 Primary.
가게 목록 필터 칩 / 지도에서 보기 / 가게 카드 Soft Text Card Action 필터 토글은 선택 상태가 즉시 보여야 합니다. 카드 자체는 큰 터치 영역입니다.
가게 상세 X / 찜 / 길찾기 / 탐정수첩에 저장 Icon Secondary Selected CTA 모달 화면으로 보고 하단 탭바는 숨깁니다. X와 찜은 스크롤해도 같은 위치. 찜 선택 시 갈색 선택 상태로 표시. 길찾기는 CTA, 수첩 저장은 Secondary/Selected로 배치.
길찾기 X / 도보 / 자전거 / 대중교통 / 경로 안내 시작 Icon Selected Secondary CTA 현재 교통수단은 선택 상태, 나머지는 Secondary. 시작 버튼은 CTA.
탐정수첩 작성 X / 메뉴 칩 / 면 식감 / 국물 농도 / 일치도 / 기록 저장 Icon Selected CTA 필수 5항목 완료 전 기록 저장 비활성. 완료 후 CTA 활성, 저장 완료 시 선택/완료 상태로 전환.
로그인 필요 모달 카카오 로그인 / 네이버 로그인 / 애플 로그인 / 닫기 CTA Outlined 권장 로그인은 CTA, 대체 로그인과 닫기는 Outlined 계층으로 둡니다.
1. 색상 위계 주황 그라데이션은 화면의 핵심 CTA에만 씁니다. 선택 완료 상태는 갈색으로 분리해 CTA처럼 보이지 않게 합니다.
2. 닫기/뒤로가기 X와 뒤로가기는 44px 네모 아이콘 버튼으로 통일합니다. X는 좌측 상단을 기본 위치로 합니다.
3. 상태 반응 누를 수 있는 선택 버튼은 반드시 선택/해제 상태가 화면에 남아야 합니다. 단순 이동 버튼만 눌림 스케일 반응으로 끝냅니다.
